## Minimax vs. MCTS Comparison

For this project, I compare Minimax and Monte Carlo Tree Search (MCTS) on Connect Four and Quarto.

## Files

- `problems.py` - This is where the code for the games is. I wrote Connect Four and Quarto, and Tic-Tac-Toe came from the project template.
- `algorithms.py` - This is where the agents (players) are defined. Right now there's just a random agent. Minimax and MCTS will be added for the final report.
- `demo.py` - This shows two random agents playing Connect Four, then Quarto.
- `comparisons.py` - will be used to play a lot of games and compare the agents. Right now it's still the template code.

## Notes

- In Quarto, the first piece is picked at random to keep things simple.

## How to Run
- `conda activate evalenv`
- `python demo.py`
